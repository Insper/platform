# Midterm

The midterm exam (*Avaliação Intermediária*, AI) of 2026.2, applied on September 25, 2026: 10 multiple-choice
questions (0.8 point each) and 1 essay question (2.0 points), 10.0 points in 120 minutes, closed book. The four
types (A, B, C and D) have the same questions, in a different order and with the options shuffled. The exam is
in Portuguese.
