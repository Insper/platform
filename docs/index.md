## [Syllabus](#syllabus)

Concepts of monolithic and microservice applications; containerization; software design patterns; application monitoring and traceability; security (authentication and authorization); messaging; distributed data; cloud computing orchestration, management systems, monitoring and configuration of virtualized resources; integration between development and operations; use of cloud platforms in production (cloud computing); automation of cloud system management — DevOps; serverless computing — FaaS (function as a service); the platform as a product for business: Infrastructure as a Service (IaaS), Platform as a Service (PaaS) and Software as a Service (SaaS); service level management (SLA — Service Level Agreement); project and operating costs of cloud systems.

## [Objectives](#objectives)

By the end of the course the student will be able to:

1. Make decisions about architectural strategies to address computational problems;
2. Implement and interconnect applications to build high-performance platforms: scalability through cloud computing techniques;
3. Administer a cloud management system, provisioning the required infrastructure as a service;
4. Build, with the help of frameworks, complete and integrated platform solutions in a professional way;
5. Design and implement robust software delivery pipelines (CI/CD);
6. Analyze, design and specify a mixed cloud computing solution based on hardware, software and networks to meet the requirements of a given service level agreement (SLA);
7. Plan and analyze the use of enterprise platforms as a basis for creating new businesses (PaaS).

## [Course Content](#course-content)

1. Architecture and microservice concepts;
2. Microservices with an API interface — RESTful;
3. Introduction to containers;
4. Introduction to and implementation of design patterns;
5. More complex design patterns: security, messaging, cache, etc.;
6. Cloud computing fundamentals;
7. Orchestration, deployment and monitoring of virtualized and distributed environments;
8. Infrastructure as a Service;
9. Software-defined networking;
10. Software as a Service;
11. Service level management.
