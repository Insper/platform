# Cartas de Estudo: Design de Sistemas { #study-cards-system-design }

Um baralho para as 16 aulas, da C1 (o que é design de sistemas) à C16 (os estudos de caso), subpáginas incluídas: 460 cartas, cada uma uma seção de uma aula, com os números da própria aula e o exemplo do BoxOffice. Há dois modos.

- **Estudar.** Leia a pergunta, responda de cabeça e vire a carta. Depois diga como foi: *errei*, *quase* ou *acertei*. As cartas que você errou voltam primeiro; as que você acertou esperam até o fim. Seu progresso fica salvo neste navegador.
- **Desafio.** Um jogo de dez rodadas: cada rodada mostra uma situação de produção ou de uma entrevista de design ("o provedor de pagamento está lento e toda thread do checkout está esperando…") e três cartas de conceito. Escolha a carta que explica ou resolve a situação. Acertos seguidos multiplicam os pontos; cada erro custa uma vida e manda a carta para a caixa *errei* do modo Estudar. São 272 situações.

Os filtros montam o baralho. Escolha um ou mais temas (F fundamentos, D sistemas distribuídos, E borda e computação, S armazenamento, M mensageria, O operações, A IA, P desempenho e casos) e, dentro deles, as aulas ou páginas de aula que quiser: estude só a aula desta semana ou, ao revisar para uma prova, só uma etapa de um design. A cor de cada carta é a sua etapa de design, a mesma do [mapa de conceitos](../concept-map/index.md): azul para requisitos e números, roxo para blocos de construção, verde-azulado para dados e consistência, laranja para operar em escala; o nome da etapa também está escrito na faixa da carta. Os pontos embaixo dão o nível: aquecimento, prática ou desafio. No teclado, a barra de espaço vira a carta e 1, 2 e 3 dão a sua nota (ou escolhem uma carta, no Desafio).

<div class="dgm" data-dgm="cartas-arq"></div>

Toda carta leva à seção da aula em que o conceito é ensinado. Para ver como os conceitos se ligam, use o [mapa de conceitos](../concept-map/index.md); para consultar fórmulas e números, a [folha de consulta](../cheat-sheet/index.md); para praticar com exercícios, o [caderno](../workbook/index.md); para ensaiar um design completo em voz alta, a [preparação para entrevistas](../interview/index.md).
