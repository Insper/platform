# Caderno: Design de Sistemas { #workbook-system-design }

Uma atividade por aula, para fazer no papel: as 16 aulas, dos requisitos e das estimativas de guardanapo aos problemas clássicos de entrevista. Cada atividade abre com a pergunta da aula e um resumo curto do que você precisa saber, seguido de exercícios de dificuldade crescente (aquecimento, prática e desafio): estimativas à mão, Lei de Little e utilização, percentis e fan-out, disponibilidade em série e em paralelo, taxas de acerto, quóruns, partições e consumidores, error budgets e burn rates, capacidade e custo, esboços de design com os componentes da paleta do simulador, trade-offs para defender e falhas para diagnosticar. Os quadros com um QR code abrem o cenário correspondente do [System Design Playground](../../../playground/index.md). As respostas comentadas estão no fim do caderno, com o raciocínio e o erro mais comum.

Use-o para revisar depois de cada aula, para se preparar para as provas e para treinar para entrevistas de system design. Enquanto trabalha, a [folha de consulta](../cheat-sheet/index.md) traz o método, as fórmulas, os números e os componentes em oito páginas. O caderno está em inglês.
