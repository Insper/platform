Endpoint removal and SIGTERM start at the same moment; without the preStop pause some proxies still send requests to a pod that no longer accepts them. Lab 10 measures it: 0 failed requests with the pause.

Ask: who restarts the pods when a node loses power? Answer: nobody — the ReplicaSet controller sees 2 instead of 4 and creates pods; the scheduler finds room.
